# Figma 实现核对 · 2026-09-21

设计来源：[Thus.Live 最终设计文件](https://www.figma.com/design/GBJVh0iLtAnjrq4pye75YS)，`06 Screens`（S01–S42）与 `07 Interaction Spec`。本次直接读取了全部 42 个画板的设计上下文；早期 HTML/PNG 不作为实现依据。

## 共用基准

- 窗口内容区 1440×900；应用标题栏 56px、状态栏 32px。根据本次用户明确要求，移除 Windows/Linux 系统标题栏和窗口菜单，使用应用内窗口控制。macOS 系统顶部菜单保留以支持平台编辑快捷键，窗口内不增加第二条标题栏。
- 固定导航宽 208px，内边距/间距 16px；文章列表宽 444px、内边距 24px。文章行高 112px，行间距 16px。
- 按钮基准 132×40、输入框 48px、弹窗宽 720px、内边距 32px、字段间距 12px。
- Noto Sans SC、JetBrains Mono 已随应用打包（附 OFL 授权），不依赖用户安装字体。标题 32/46，分组标题 24/36，正文 16/28，界面 14/22，说明 12/20。
- 写作工具栏 72px；分栏默认各占一半，拖动时每侧至少 400px；窄窗口单栏并可切换预览。按后续用户要求，纯写作及完整预览铺满侧栏外的剩余宽度，文章操作按钮靠右。
- 文章库单击会独立读取并预览文章，不改变正在编辑的缓冲区。正文渲染继续采用项目 CSS；真实文章内容、日期、状态、项目主题与 Figma 示范文案可能不同。

## 验证入口

- `pnpm build`：类型检查、网页资源与 Electron 主进程构建。
- `pnpm test`：项目读写、资源重名、并发文件冲突和 Markdown 渲染。
- `pnpm test:e2e`：实际 Electron 操作、界面截图、窗口菜单/内容尺寸、最小化/最大化/还原和未保存关闭保护。

本次没有重新生成 `release` 中的安装包；开发运行和本地构建使用新实现。

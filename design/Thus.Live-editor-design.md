# Thus.Live 桌面博文编辑器 · 设计方案

> 最新交付：已完成 Figma 可编辑页面与交互规范，后续以 [完整交互规范](./Thus.Live-interaction-spec.md) 及 [Figma 文件](https://www.figma.com/design/GBJVh0iLtAnjrq4pye75YS) 为准。以下保留初版方案记录；文章库已升级为固定导航、独立文章列表和按需年月筛选，写作时收起文章列表。

本轮交付界面与交互设计，不实现桌面应用。只读分析 `blogpath`，设计产物位于独立任务目录。

## 设计方向

沿用 Thus.Live 已有的阅读风格：白色／中性深灰背景、青绿色强调、细线分隔、少量圆角。浅色主文字 #242628，强调色 #2f6f61；深色背景 #17191a，强调色 #8fc3af。工具栏紧凑，正文留白充分。界面使用项目中文无衬线字体栈，源码使用项目等宽字体栈。

默认主界面由文章库、Markdown 编辑区、文章预览组成。建议桌面初始尺寸 1440 × 960，文章库宽 220 px，其余区域均分，分栏可拖拽。窗口较窄时默认单栏并保留写作／预览切换。文章信息按需展开，不占用常驻第四栏。交互稿在较窄的会话区域以纵向堆叠演示。

## 已核对的项目约束

- 文章位于 `content/posts/YYYY/MM/DD/slug.md` 或 `content/posts/YYYY/MM/DD/slug/index.md`；日期由目录决定。
- 元信息包括 title、description、tags、draft、updated；date 如存在必须与目录一致。作者来自全站配置，不新增每篇文章作者字段。
- `draft: true` 在当前开发与构建路由中都会被排除。非草稿仅表示参与构建，不能据此显示“已上线”。
- 正文采用 `src/styles/markdown.css`，依赖 `src/styles/theme.css` 的主题变量、字体和文章布局。
- `.vitepress/config.ts` 使用 VitePress 的高亮、行号、公式和扩展语法，含脚注、任务列表、定义列表、缩写、高亮、上下标及自定义 Mermaid 组件。
- `ArticleView.vue` 将标题、摘要、标签、日期与正文分开展示，二、三级标题生成目录；标题去重还依赖配置中的 Markdown 规则。

## 首次启动与项目设置

首次启动呈现“从你的项目，开始写作”。使用原生文件夹选择器选择项目根目录，也支持粘贴绝对路径。选择后显示完整目录及检测结果：文章目录、主题与正文样式、渲染配置、文章数量。检测成功后“进入写作空间”可用。

未选择目录时保留空状态；不存在的目录显示“目录不存在，请重新选择”；无访问权限显示具体目录并提供重试；文章目录不存在时允许重新选择，不自动创建；样式缺失时显式提供“使用基础预览”，预览持续标注降级状态。配置加载失败仍允许编辑，并显示具体失败项。

路径和窗口状态存入编辑器自己的用户配置目录。以后启动恢复最近项目；路径失效时回到设置页。工具栏始终保留项目切换入口。切换前处理未保存修改。

## 写作流程

1. 文章库按日期倒序排列，显示标题、日期、草稿标识。文章少时直接列出，增多后提供搜索与草稿筛选。
2. 新建时填写标题、文件名和日期，默认草稿。预先显示完整保存路径，并校验日期、文件名、同名文件及两种目录结构的路由冲突。图片较多可选择独立文章文件夹。
3. 标题与正文分开编辑。文章信息面板填写摘要、标签、草稿和更新日期；保留原文件未知 frontmatter 字段，避免表单保存丢失数据。高级用户可切换完整 Markdown 源码；YAML 无法解析时禁止表单覆盖原文，保留源码修复入口。
4. 写作／分栏／预览三种视图。分栏默认同步滚动，支持关闭；映射依据 Markdown 源行和渲染节点，不直接按滚动百分比同步。预览模式可切换桌面与窄屏文章宽度，并使用项目明暗主题。
5. Ctrl+S 保存，状态区区分已保存、未保存、保存失败。自动恢复副本写入应用目录；默认不自动覆盖项目文件。文件保存采用临时文件与原子替换策略，并在失败时保留缓冲区。
6. 关闭、切换项目或覆盖存在冲突的文件时提供明确的保存／放弃／取消选择。外部文件变更：无本地修改自动重载，有本地修改则提供差异比较、重新加载与另存为，不静默覆盖。

## 项目样式与预览设计

正式编辑器读取项目样式，而不是维护一份长期复制的 CSS。预览位于独立的渲染容器，保留 `.markdown-body`、文章头部结构、主题变量和 `.dark` 作用域；站点样式不能影响编辑器工具栏。

CSS 只决定外观。渲染适配层还需要对齐项目的 VitePress Markdown 配置、Shiki 双主题代码高亮、MathJax、Mermaid、代码分组、标题去重及目录生成。将草稿缓冲区交给预览适配层渲染，不修改实际 draft 字段，也不通过启动现有站点来绕过草稿排除。扩展配置无法识别时明确显示不支持项，不能声称与站点完全一致。

本地图片以文章目录为基准解析；根路径资源映射到 `content/public/`。插入图片默认复制到当前文章附近的 assets 目录，处理重名，插入相对地址并要求填写替代文字。文章链接在预览中优先打开项目内对应文章；外链交由系统浏览器。

监听样式变化并重新加载；编译失败保留上次成功预览并提示。预览执行环境隔离文件系统写入能力，禁用正文脚本。未知自定义组件提供可见占位和错误说明。

## 扩展语法兼容清单（首版必需）

已在项目 `.vitepress/config.ts`、`package.json`、`ArticleView.vue`、`MermaidDiagram.vue` 和现有 Markdown 指南中找到的能力，全部纳入正式编辑器首版兼容范围。下表为已确认的适配要求，不代表当前交互稿已实现这些渲染能力。

| 类别 | 必须兼容的内容 | 验收要点 |
| --- | --- | --- |
| 代码展示 | Shiki 的 github-light / github-dark 配色、语言标记、行号、指定行高亮、差异行、聚焦行 | 明暗切换与站点一致；复制时遵循站点忽略删除行等规则 |
| 代码分组 | `::: code-group`、文件名标签、多段代码 | 标签可以切换，内容与高亮正确 |
| 数学公式 | 行内公式、独立公式，项目启用的 MathJax 渲染 | 长公式可横向查看；错误不阻断其他正文 |
| Mermaid | mermaid 围栏转为项目图表组件 | 跟随明暗主题重新渲染；源码可展开；出错自动展示源码与错误提示 |
| 提示与折叠 | tip、warning、danger、info、details 容器 | 标题、配色、嵌套内容与展开交互一致 |
| 脚注 | markdown-it-footnote | 编号、跳转、返回正文链接正确 |
| 任务列表 | markdown-it-task-lists | 勾选状态正确呈现；预览交互不隐式改写源文 |
| 定义与缩写 | markdown-it-deflist、markdown-it-abbr | 定义列表布局与缩写说明正确 |
| 扩展行内格式 | markdown-it-mark、markdown-it-sub、markdown-it-sup | 高亮、上下标与相邻文本布局正确 |
| Emoji | Unicode 表情和指南中的简码 | 沿用项目实际解析结果，不自行定义替换规则 |
| 标题与目录 | 项目的首个一级标题去重规则；二、三级标题目录 | 不重复展示文章标题；锚点、目录跳转与同步滚动正确 |
| 基础语法与资源 | 表格、链接、图片、引用、删除线及静态 HTML | 相对路径按文章位置解析；保留站点排版，不执行正文脚本 |

项目设置中增加可展开的“渲染兼容性”列表，逐项显示“已适配／依赖缺失／加载失败／未识别”，其中“已适配”只有在实际渲染适配成功后才能显示。首次检测不能仅凭配置中出现插件名称就宣称兼容。

实现优先使用与项目一致的 VitePress 版本及插件配置，补齐依赖 Vue 上下文的图表和代码组交互。目录选择与只读检测本身不执行项目配置脚本；需要执行的编译与组件渲染放在隔离进程中，产物写入编辑器缓存目录。当前项目的已知扩展不可静默退化为普通文本；缺失依赖时显示修复说明并保留原始内容。未来新增、无法识别的扩展单独提示适配状态。

验收以两篇现有指南为基础，补充覆盖遗漏语法的测试样例，所有样例与渲染产物放在编辑器测试目录。逐项比对站点与编辑器的结构、视觉、交互以及明暗主题，另外测试未保存内容、草稿和错误语法。所有已确认项通过后，才可认定完成项目扩展语法兼容。

## 保存与发布语义

首版主操作是“保存”。不设置会让用户误认为已经部署的“发布”按钮。将草稿设为非草稿时说明“将参与下次站点构建”；构建与部署作为未来独立功能设计。未来日期不等于定时发布。

更改发布日期或文件名会改变文章地址，应通过独立的“移动／重命名”流程展示新旧路径和地址、受影响的相对资源与内部引用，并提示已部署地址需要重定向。

## 首版范围与验收

首版包括项目设置、文章打开与新建、元信息编辑、源码编辑、项目样式预览、草稿预览、图片插入、保存和冲突处理。Git、部署、AI 写作与多项目并行不在首版范围。

验收覆盖：首次选目录及失效恢复；两种文章目录；草稿无需改标记即可预览；未知元信息保留；保存失败不丢内容；外部变更冲突；主题热更新；相对图片与根路径图片；标题去重；表格、脚注、任务列表、代码组、公式和 Mermaid 的明暗主题效果。用项目现有两篇指南作为回归样本，预览与站点构建结果逐项比对。

## 本轮交互稿边界

可体验项目设置、文章切换、新建草稿示意、文章信息、基础编辑联动、三种视图和主题选项。文章为现有内容的节选与设计示例，保存仅保留在演示内存。排版依据已读项目 CSS；并未接通真实文件选择、项目写入、完整 VitePress 渲染或部署。

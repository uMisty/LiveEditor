# Thus.Live Editor v0.1.0

这是 Thus.Live Editor 的首个公开版本。

Thus.Live Editor 是为 Thus.Live 博客准备的本地桌面写作工具。它直接连接已有博客项目，在保留原有目录结构和发布流程的前提下，提供 Markdown 写作、实时预览、文章管理、首页编辑和博客信息维护。文章、图片和站点配置仍保存在用户选择的本地项目中；保存内容不会自动上传或发布网站。

## 主要功能

### Markdown 写作与预览

- 写作、分栏和完整预览三种布局。
- 基于 CodeMirror 6 的 Markdown 编辑器，支持同步滚动、编辑字号和分栏宽度。
- 支持浅色、深色和跟随系统主题。
- 可在正文编辑与完整 Markdown 源码之间切换。
- 支持 Shiki 代码高亮、代码组、MathJax、Mermaid、提示容器、折叠详情、脚注、任务列表、定义列表、缩写、高亮和上下标等常用 VitePress Markdown 能力。

### 文章、首页与博客信息

- 浏览全部文章和草稿，按关键词、日期与标签筛选，并可快速打开文章。
- 新建草稿，编辑标题、摘要、标签、状态和更新日期。
- 移动或重命名文章，并更新可识别的 Markdown 引用。
- 将文章移入系统回收站，或将当前内容另存副本。
- 编辑 `content/index.md` 首页，同时保留 `layout: home` 等既有元信息。
- 编辑站点名称、作者、首页标题、简介、语言、网址、头像、页脚和每页文章数，并保存到 `site.profile.json`。

### 图片与文件保护

- 可选择、拖入或粘贴本地图片，并复制到文章附近的 `assets` 目录。
- 同名图片可以保留两份或引用现有文件。
- 保存前比较文件版本，避免覆盖其他程序的修改。
- 检测外部文件变化，并提供未保存提醒、保存失败保护和恢复副本。
- 支持只读连接项目；项目配置只作静态检查，不执行其中的脚本。
- Markdown 在独立进程中渲染，净化后在沙箱页面中展示。

### 版本更新提示

- 启动后检查 GitHub 最新稳定 Release，也可在“关于软件”中手动检查。
- 仅在稳定版本高于当前安装版本时提示前往 GitHub 更新。
- “不再提示此版本”只忽略当前检查到的版本；后续更高版本仍会提醒。
- 网络错误和检查超时不会影响本地编辑，应用不会自动下载或安装更新。

## 下载与安装

- Windows：推荐 `.exe` 安装程序；`.zip` 为免安装版本，解压后需保留完整目录。
- macOS：提供 `.dmg` 和 `.zip`。
- Linux：提供 `.AppImage` 和 `.deb`；AppImage 可能需要先执行 `chmod +x` 授予执行权限。
- Release 附带 `SHA256SUMS.txt`，建议安装前核对下载文件。

Windows 文件当前尚未完成代码签名，系统可能显示未知发布者警告。macOS 文件尚未完成签名与公证。请只从本项目 GitHub Releases 页面下载安装包。

## 开始使用

1. 启动应用并选择已有的 Thus.Live 项目根目录。
2. 检查连接结果后进入写作空间。
3. 从侧栏打开博客信息、首页、全部文章或草稿。
4. 修改后点击“保存”，或按 `Ctrl/⌘ + S`。
5. 按博客项目原有流程构建并部署站点。

应用内保存不会自动发布博客。草稿设为非草稿后，也仍需重新构建和部署站点。

## 兼容性与已知限制

- 自定义 Vue 组件需要在实际博客站点中查看。
- 不展开 `<<<` 外部代码片段和 `@include`。
- 内置预览不加载远程图片。
- 移动文章时只更新可识别的 Markdown 链接；动态引用和线上重定向需手动处理。
- Markdown 文件最大支持 5 MB，单张导入图片最大支持 25 MB。
- Windows 已完成主要功能验证；macOS 和 Linux 仍需更多实际环境测试。
- 更新需要前往 GitHub Releases 手动下载安装，暂不提供应用内自动安装。
